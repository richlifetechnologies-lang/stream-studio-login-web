Plans & Pricing

Set the price, the default monthly minutes (0 = unlimited), device limit, and which features each plan includes. A plan's features decide capability: voice only = audio calls; video + voice = video & audio calls. Price is a label — billing is handled offline by the administrator.

Add / edit a key pair

Store your video key (fal.ai) and voice key (ElevenLabs). Keep several pairs on file and mark one as the global default (the master fallback). Link a specific pair to a user on the Users tab. Keys are readable only by admins and the server; regular users can never read them.
